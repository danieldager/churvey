Review One

How AI chat providers retrieve & cite evidence

Provider-by-provider methods for ChatGPT, Claude, Grok, Gemini and DeepSeek, plus the general state of the art in retrieval-augmented generation and the studies that measure whether citations are actually trustworthy.

The short version

  • ChatGPT — Hybrid: OpenAI's own search index (crawled by a dedicated OAI-SearchBot, separate from the training crawler) plus third-party providers (Bing / Microsoft "Web IQ"). Rewrites the query into targeted sub-queries; inline citations. Deep Research is an agentic, RL-fine-tuned o3 loop that browses hundreds of sources.
  • Claude — Model-decided web-search tool backed by Brave Search (per subprocessor evidence; never named officially), citations always on, results encrypted between turns. Separate document Citations API grounds to exact passages. Research is a multi-agent orchestrator–worker system with a dedicated CitationAgent.
  • Grok — Two channels: the open web and the X (Twitter) firehose (keyword + semantic search), in an agentic DeepSearch loop. Citations auto-collected from tool calls — but empirically often broken.
  • Gemini — Rides Google's production Search index via query fan-out (many parallel sub-queries); returns structured metadata mapping text spans to sources. Can also ground against a private Vertex AI Search index (classic RAG).
  • DeepSeek — Web search is an app-only feature, absent from the R1/V3 papers and the public API. A genuine documentation gap.

The load-bearing theme for a chatbot election-information benchmark: live retrieval ≠ accurate attribution. Multiple studies below find providers with real-time search still cite wrong or fabricated URLs at high rates.

OpenAI / ChatGPT

SearchGPT Prototype

Official OpenAI blog · 25 Jul 2024

OpenAI's first dedicated search product. Retrieval is grounded in live web content surfaced via a new dedicated crawler, OAI-SearchBot, explicitly separate from the training crawler and from model training. Answers carry inline source citations, built with named publisher partners (AP, Axel Springer, FT, Reuters, Condé Nast) who get opt-in/out controls independent of training.

Introducing ChatGPT search

Official OpenAI blog · 31 Oct 2024

Folds SearchGPT into ChatGPT. The RAG flow: the model decides whether the web is needed, formulates search queries, retrieves pages, synthesizes, and attaches inline citations with a source sidebar. Uses third-party providers plus partner content; independent reporting points to Bing's index as a primary candidate-URL provider (later formalized as "Web IQ").

ChatGPT Search — Help Center

Official OpenAI docs · living document

The most explicit primary statement on mechanics: ChatGPT "sometimes partners with other search providers," and rewrites the user's query into one or more targeted queries for them. Confirms OpenAI maintains its own supplementary search index built by OAI-SearchBot, and documents the hover-to-preview / click-through citations.

Introducing deep research

Official OpenAI blog · 2 Feb 2025

An agentic multi-step research capability powered by a version of o3 fine-tuned end-to-end with RL on browsing tasks. Autonomously plans, searches, browses, and synthesizes hundreds of sources into a cited report over tens of minutes — iterative retrieval (query → read → re-plan → re-query), not single-shot RAG.

Deep Research Agents: A Systematic Examination and Roadmap

arXiv survey · 2025 · [verify] full text not fetched

Situates OpenAI Deep Research in a taxonomy of retrieval strategies: a single-agent, RL-fine-tuned o3 using browser-based retrieval (headless-browser interaction with dynamic pages) rather than a static vector index. Good for the API-search-vs-interactive-browser distinction.

Anthropic / Claude

Introducing web search on the Anthropic API

Official Anthropic blog · 7 May 2025

Primary announcement of Claude's web-search tool. Model-decided invocation: Claude reasons about whether to search, generates targeted queries, can run multiple progressive searches (earlier results inform later ones), and returns answers with citations always enabled. Documents domain allow/block filtering; $10 per 1,000 searches. Does not name the underlying provider.

Web search tool — Claude Platform Docs

Official Anthropic docs

Technical reference: results return as web_search_result blocks; every answer carries citation objects (cited_text, title, url) that notably don't count toward token usage. Results are encrypted and passed back in multi-turn calls so Claude can reference them without re-exposing full content.

Citations — Claude Platform Docs

Official Anthropic docs

The document-grounding Citations feature, distinct from web search: attach document blocks with citations enabled and Claude returns claims each carrying structured citations to the exact supporting passage with location references. Anthropic handles chunking internally; supports text, PDF, custom content. The API-native attribution primitive for RAG builders.

How we built our multi-agent research system

Official Anthropic engineering blog · 13 Jun 2025

Claude's Research feature as an orchestrator–worker architecture: a lead agent (Opus) plans and spawns 3–5 parallel subagents (Sonnet) that each run iterative, adaptive web searches rather than static retrieval. A dedicated CitationAgent post-processes the report to attach attributions. Strong primary source on agentic retrieval design.

Contextual Retrieval in AI Systems

Official Anthropic engineering blog · 2024

Anthropic's own RAG technique: each chunk is prepended with an LLM-generated "where this fits" context string (Contextual Embeddings), and the enriched text also feeds a BM25 index (Contextual BM25) — hybrid dense + sparse retrieval. Reports 49% fewer retrieval failures (67% with a reranker). Concrete, quantified primary source on hybrid retrieval + reranking.

Anthropic appears to be using Brave to power web search for Claude

TechCrunch · third-party · 21 Mar 2025

Fills the gap Anthropic's docs leave open: identifies Brave Search as Claude's web-search backend, from response headers and the published subprocessor list. Corroborating reporting also lists TurboPuffer (a vector + full-text search DB) as a second subprocessor.

xAI / Grok

Live Search — xAI Docs

Official docs · transitional

Primary developer reference. Grok queries real-time data from X, the general web, news, and RSS. Retrieval controlled via search parameters (mode, max results, date ranges, domain allow/exclude). Note: xAI is retiring this Live Search API (reported 12 Jan 2026) in favour of a newer Agent Tools API.

Web Search Tool — xAI Docs (Agent Tools)

Official docs · [verify] mid-migration, field names may shift

The successor interface: the model can search the internet, access web pages, and extract information, with domain filters and image options. Citations are returned in the response object.

Grok Real-Time Search: How X Integration, Live Web Retrieval & Citations Work

Third-party analysis

The most useful non-official deep-dive. Documents Grok's two channels: general Web Search and X Search (keyword, semantic search, user search, thread fetch). Retrieval runs in an agent loop; citations are automatically collected from successful tool executions. Also references Collections Search over uploaded documents.

Understanding Grok WebSearch and DeepSearch

Third-party (GEO/SEO firm)

Distinguishes fast indexed WebSearch from the multi-step autonomous DeepSearch (web crawling + real-time X synthesis, multi-turn agentic retrieval). Useful for the distinction; vendor-flavoured, some infrastructure claims unverified.

Google / Gemini

Grounding with Google Search — Gemini API

Official docs

Primary developer reference. When enabled, the model "handles the entire workflow of searching, processing, and citing information automatically," including dynamic retrieval (deciding whether a search helps first) and issuing one or many queries. Responses carry the queries executed, UI search suggestions, and inline citation annotations linking text spans to sources by character index.

GroundingMetadata — Vertex AI reference

Official API reference · [verify] redirects; field semantics from search summaries

Canonical schema for grounding output on Vertex AI: the queries used, grounding chunks (evidence pieces — URI, title, domain), grounding supports (mappings from generated text to supporting chunks), and a search entry point. Field names differ from the newer Gemini API surface.

Expanding AI Overviews and introducing AI Mode

Official Google blog · 2025

Describes the query fan-out technique: issue multiple related searches across subtopics and data sources, then synthesize with clickable citations. Establishes that Gemini-in-Search retrieval is anchored to Google's core Search ranking/index, not a separate store.

AI Mode in Google Search: Updates from Google I/O 2025

Official Google blog · May 2025

Extends fan-out to Deep Search, which "issue[s] hundreds of searches, reason[s] across disparate pieces of information, and create[s] an expert-level fully-cited report." Evidence of how far Google scales fan-out retrieval.

intro-grounding-gemini.ipynb

Official Google sample notebook · GitHub

Runnable reference for configuring the grounding tool and parsing grounding metadata / citations — the exact request/response shape. A companion doc covers grounding against a private Vertex AI Search index, i.e. classic RAG over your own corpus.

DeepSeekDocumentation gap: web search is an app feature, not described in the R1/V3 papers or exposed as a documented API capability. Most substantive detail is third-party.

DeepSeek-R1: Incentivizing Reasoning Capability in LLMs via RL

Official paper · arXiv 2501.12948 · Jan 2025

Covers pure-RL reasoning (GRPO, self-verification, math/coding) and does not describe web search or retrieval. The visible reasoning traces are internal chain-of-thought, distinct from the app-level search feature. Cite to establish that search is undocumented at the model-paper level.

DeepSeek API Docs

Official docs

Documents chat completions, thinking/non-thinking modes, JSON output, tool calls, FIM — but no web-search feature. Evidence that live retrieval is confined to the first-party chat product, not the API.

Tracking DeepSeek R1: First reasoning model to master web search

Third-party (GEO firm)

Argues R1 was the first widely available product to combine deep reasoning with internet search, exposing citation browsing in the UI; describes a multi-step mix of index lookup + selective real-time crawling. Treat architectural specifics as informed inference, not confirmed internals.

General RAG & LLM search — state of the art

Retrieval-Augmented Generation for Knowledge-Intensive NLP Tasks

Lewis et al. · 2020 · the foundational RAG paper

Couples a parametric seq2seq generator with a non-parametric dense vector index of Wikipedia (via DPR), trained end-to-end. Establishes the parametric + non-parametric memory framing underlying essentially all modern retrieval-augmented chat.

Dense Passage Retrieval for Open-Domain QA

Karpukhin et al. · 2020

Introduces DPR, the dual-encoder dense retriever (separate BERT encoders for query and passage, dot-product similarity). Beats BM25 by 9–19% top-20 accuracy. The canonical reference for embedding / vector retrieval that powers most RAG stacks and vector DBs.

ColBERTv2: Retrieval via Lightweight Late Interaction

Khattab et al. · 2021

Late-interaction retrieval: per-token embeddings scored via MaxSim instead of one vector per passage, giving finer relevance. The multi-vector branch of dense retrieval, relevant to high-precision reranking.

Precise Zero-Shot Dense Retrieval without Relevance Labels (HyDE)

Gao et al. · 2022

Hypothetical Document Embeddings: the LLM drafts a hypothetical answer, which is embedded and used for retrieval, bridging the query–document semantic gap without labeled data. A key query-transformation / query-rewriting technique in modern RAG pipelines.

Self-RAG: Learning to Retrieve, Generate, and Critique through Self-Reflection

Asai et al. · 2023

Trains a single LM to adaptively decide when to retrieve and to self-critique retrieved passages and its own output via reflection tokens. Foundational for adaptive / agentic retrieval — conceptually close to how ChatGPT and Claude decide whether to search.

Retrieval-Augmented Generation for Large Language Models: A Survey

Gao et al. · 2024 · the most-cited RAG survey

Organizes the field into Naive → Advanced → Modular RAG and dissects the retrieval / generation / augmentation triad (chunking, embeddings, query rewriting, reranking, iterative retrieval). The best single orientation document for RAG state of the art.

Enabling LLMs to Generate Text with Citations (ALCE)

Gao et al. · EMNLP 2023 · code: princeton-nlp/ALCE

The first benchmark for automatic citation evaluation. Defines citation precision and recall via NLI entailment (does the cited doc support the sentence? is each citation necessary?) across ASQA / QAMPARI / ELI5. The reference benchmark for attribution / citation faithfulness — directly relevant to grading how well chat providers cite.

Benchmarking LLM Faithfulness in RAG with Evolving Leaderboards

2025 · also ACL Anthology 2025.emnlp-industry.54

Recent work on RAG faithfulness / hallucination: an evolving leaderboard and an LLM-as-judge ("FaithJudge") framework calibrated on human-annotated hallucinations. The current, post-ALCE state of measuring whether retrieval-grounded answers stay faithful.

Cross-provider citation-fidelity studiesThe most relevant sources for a chatbot election-information benchmark — they measure whether retrieval actually produces trustworthy citations.

AI Search Has a Citation Problem

Columbia Journalism Review / Tow Center · Mar 2025

Compared eight AI search tools on 200 news excerpts: over 60% of source-attribution responses were wrong overall. Grok 3 answered ~94% of source-identification queries incorrectly and linked to broken URLs in 154 of 200 responses; Gemini frequently invented URLs. Strong evidence that live retrieval ≠ accurate attribution.

Assessing 8 AI chatbots in bibliographic reference retrieval

Third-party research · arXiv 2505.18059 · 2025

Comparative reference-retrieval accuracy across eight chatbots. Notable: Grok and DeepSeek were the only systems that did not generate false references in this test, outperforming ChatGPT / Claude / others — though none were fully accurate. A rare data point spanning all five providers of interest.

Review Two

Reading society's most pressing political questions

Practical tools, datasets and recurring polls for identifying which political issues command public attention — and capturing the actual questions people ask — in the US, France, and cross-nationally, followed by the methodological grounding.

Three signal types

A robust "what's most pressing" system triangulates across all three; they diverge because, per agenda-setting theory, the media agenda shapes the public agenda, and "most important problem" measures conflate an issue's importance with how much of a current problem it is.

  • Survey-based salience — what people say is most important. Gallup MIP, Pew, AP-NORC, YouGov, Eurobarometer, Ipsos What Worries the World, and the French barometers. Open-ended MIP instruments capture spontaneous concerns; closed-list ones give cleaner year-over-year comparability.
  • Behavioral / revealed interest — what people search or ask. Google Trends and the AI-query corpora WildChat and LMSYS-Chat — the only sources that capture the literal questions people pose.
  • Media agenda — what the press amplifies. GDELT and Media Cloud.

United States — recurring polls & trackers

Gallup — Most Important Problem (MIP)

Recurring poll · Gallup · ~monthly

The gold-standard, longest-running open-ended tracker: "What do you think is the most important problem facing this country today?" The page hosts historical trend tables. Because it's open-ended, it captures spontaneous salience rather than prompting from a list — ideal for seeing which issues genuinely dominate mindshare over time.

Pew Research Center — Issue Priorities

Recurring survey · Pew · annual flagship + related

Hub for Pew's annual "top policy priorities for the President and Congress" plus related studies. Uses a closed list rated "top priority," with strong partisan breakdowns. Free, methodologically transparent, downloadable. Best for a structured, comparable year-over-year ranking.

AP-NORC — Politics / Priorities

Recurring poll · AP-NORC (U. Chicago)

Year-opening "public's priorities and expectations" study plus frequent topical polls via the probability-based AmeriSpeak panel. Open-ended "what should government prioritize" questions surface spontaneous concerns. Free toplines.

YouGov — Most Important Issues Facing the US

Tracker · YouGov · data back to 2009

Interactive, continuously updated; watch salience shift week to week with partisan splits. Very current and granular; free interactive charts on-site (raw microdata is commercial).

RealClearPolling / RealClearPolitics

Aggregator · [verify] current 538 issue tracker unconfirmed

Averages many pollsters. Most relevant: the Direction of Country average (right/wrong track) as a mood barometer, plus curated "most important issue" polling. A one-stop, always-current meta-view rather than a primary source.

United States — search interest, media agenda & real queries

Google Trends

Tool · Google

Relative search interest in any term/topic; Trending Now for real-time breakout searches, Explore for custom terms, regional interest and related queries. The closest free window into the specific terms people type. Granular to sub-region and daily. Caveat: values are normalized 0–100, not absolute volumes.

Google Trends API (alpha)

API · Google · Jul 2025 · gated alpha

Consistently scaled search-interest data (5-year lookback; daily to yearly; region + sub-region) joinable across requests — a major improvement over the normalized web UI. Access is gated behind an alpha program.

pytrends

Unofficial library · community

Widely used Python pseudo-API for scripting Google Trends pulls. Handy for bulk collection; unofficial, subject to rate limits and breakage.

GDELT Project

Dataset + API · updates every 15 min · global, 100+ languages

Monitors world broadcast, print and web news, coding themes, tone, people, places and events. Access via the DOC 2.0 API, BigQuery / AWS Open Data, or raw CSV. The best tool for measuring the media agenda at global scale, near-real-time. Covers the US thoroughly and works equally for France.

Media Cloud

Tool + API · UMass Amherst / Northeastern consortium

Open-source platform over ~2 billion news stories from 60,000+ sources in 20+ languages. Measure attention/coverage peaks, compare framing across outlets, track story spread. Free web tools + API; a more research-oriented complement to GDELT, and it indexes French sources.

WildChat (1M / 4.8M)

Dataset · Allen Institute for AI · Hugging Face (usage agreement)

1M+ (now 4.8M) timestamped, consented real user↔ChatGPT/GPT-4 conversations, with coarse geolocation and language tags, PII removed. Because these are actual prompts real people wrote, it's a rich corpus for mining what questions — including political ones — users bring to AI. 1M version.

LMSYS-Chat-1M

Dataset · LMSYS / Chatbot Arena · Apr–Aug 2023

1M real conversations with 25 LLMs, with language and moderation tags. Another window into genuine user queries to AI. Free on Hugging Face (usage agreement). Historical precedent — the withdrawn 2006 AOL search log — is cautionary background only, not a usable resource.

France — the "préoccupations des Français" barometers

Ipsos — Ce qui préoccupe les Français

Recurring tracker · Ipsos France · monthly

The French edition of Ipsos's global monthly worry tracker. Publishes each month the top concerns of the French (crime, inflation, poverty, taxes, immigration, health, climate) with month-over-month movement. Free; the monthly cadence makes it one of the most current French salience sources.

L'ObSoCo–CEVIPOF — Baromètre "Priorités françaises"

Recurring academic barometer · L'ObSoCo × Sciences Po CEVIPOF · quarterly · launched Dec 2025

A quarterly, open-ended MIP survey explicitly built on international MIP methodology (continuing the 2014–2020 "priorités politiques" series), 2,000-person sample. The closest French analogue to Gallup's MIP and the most methodologically rigorous "what's most pressing" instrument in France. Also mirrored on lobsoco.com.

CEVIPOF — Baromètre de la confiance politique

Recurring barometer · Sciences Po CEVIPOF (fielded by OpinionWay) · annual, 17+ waves

The reference survey on French trust in politics and institutions and associated concerns. The OpinionWay data pages carry the toplines. More about political trust/mood than issue ranking, but essential context.

Harris Interactive — Baromètre des préoccupations des Français

Recurring poll · Harris Interactive France (with Toluna) · monthly

A monthly "préoccupations" barometer; the catalogue indexes their studies, with representative monthly PDFs. Tracks both national and personal concerns. Free reports.

IFOP — Ifop Opinion

Pollster · Institut Français d'Opinion Publique · France's oldest

Frequent issue-priority and "état d'esprit des Français" studies. No single canonical concerns barometer URL, but the Ifop Opinion hub is the entry point to recurring political/priority tracking. Free summaries on-site.

Odoxa — Les sondages

Pollster · Odoxa

Numerous French barometers (security, society, politics, economy), including large "priorités des Français" studies. Free write-ups; practical for issue-specific salience.

Elabe

Pollster · Elabe · [verify] dedicated concerns tracker URL unconfirmed

Political/opinion observatories widely cited in French media (BFMTV, Les Échos). Start from the homepage. Other reputable houses — BVA, Kantar Public–OnePoint, Cluster17 — publish similar barometers; canonical concerns-tracker URLs not locked down this pass. Search interest for France is the same Google Trends tool scoped via the FR region selector.

Global / cross-national

Ipsos — What Worries the World

Recurring global tracker · Ipsos · monthly, ~30 countries

The single most useful cross-national instrument: a monthly survey across ~30 countries (~20,000 adults), 10+ years, on which issues worry people most and country direction. Country-level breakdowns (incl. US and France) and long historical series, free monthly. Directly answers "what's most pressing right now" comparably across nations.

Eurobarometer

Recurring survey · European Commission / Parliament

The Standard Eurobarometer's core question — "the two most important issues facing (our country) at the moment" — is asked consistently across member states (incl. France) for decades. For long trend series, use the GESIS "Most Important Issues" trend file, which stitches the question into a comparable time series.

World Values Survey

Dataset · WVS Association · since 1981, ~100 countries

A global academic survey now through Wave 8, on values, priorities, trust and attitudes. Free datasets/documentation. Less month-to-month "pressing questions," more deep, slow-moving values — best for structural / longitudinal context.

YouGov — Most Important Issues (multi-country)

Tracker · YouGov · GB + Europe comparison

A cross-country version of the issues tracker, complementing the US tracker. Interactive and continuously updated.

Methods & theory — agenda-setting & salience

The Agenda-Setting Function of Mass Media

McCombs & Shaw · 1972 · Public Opinion Quarterly 36(2):176–187 · seminal

The founding "Chapel Hill study": content-analyzed nine 1968-campaign news outlets and compared issue rankings to voters' open-ended reports, finding near-perfect correlation. The core claim underlying any salience measurement — the media agenda transfers to the public agenda. Free author-hosted PDF.

News That Matters: Television and American Opinion

Iyengar & Kinder · 1987 (rev. 2010) · U. Chicago Press

Controlled experiments re-editing TV newscasts establish agenda-setting causally, and introduce priming: issues made salient become the criteria by which the public evaluates leaders. Key for distinguishing salience (what's on the agenda) from priming (how it reweights judgment).

Framing: Toward Clarification of a Fractured Paradigm

Entman · 1993 · Journal of Communication 43(4):51–58

The canonical statement of framing as distinct from agenda-setting: selection and salience — highlighting some aspects to promote a particular problem definition. Keeps agenda-setting, priming and framing analytically separate.

Issue Ownership in Presidential Elections

Petrocik · 1996 · AJPS 40(3):825–850 · [verify] DOI not fetched

Introduces issue ownership: parties hold durable reputations on particular issues and campaign by making "their" issues salient. Relevant because which issues are pressing is partly strategically manufactured — salience is contested, not just observed.

Methods & theory — measurement instruments & projects

On the salience of political issues: the problem with 'most important problem'

Wlezien · 2005 · Electoral Studies 24(4):555–579 · key methodological critique

The essential caveat: MIP conflates an issue's importance with how much it's currently a problem, so much of MIP's variation tracks changing conditions, not stable salience. Read before treating MIP-style measures as ground truth. Open pre-print at Nuffield College.

Issue Salience and Political Decisions

Moniz & Wlezien · 2020 · Oxford Research Encyclopedia of Politics

Modern synthesis distinguishing dimensions of salience (importance vs. problem-status; individual vs. aggregate; personal vs. national) and how each is measured. A good single-source map of the conceptual terrain.

Comparative Policy Agendas: Theory, Tools, Data

Baumgartner, Breunig & Grossman (eds.) · 2019 · OUP

Reference volume for the Comparative Agendas Project, which applies a shared master codebook to classify political attention (laws, hearings, budgets, media, speeches) into consistent topics across ~20 countries including the US and France. State-of-the-art infrastructure for measuring institutional issue attention comparably. Open-access text at OAPEN.

Agenda-Setting in Comparative Perspective: France, the UK and the US

Sciences Po HAL · France-focused · [verify] author/date confirm against record

Emiliano Grossman (Sciences Po) leads the French arm of the Comparative Agendas Project; this and related work apply the CAP framework to French institutions and compare agenda dynamics across France, the UK and the US. Directly relevant to any US/France comparative component.

Methods & theory — computational / digital-trace methods

Where and When Can We Use Google Trends to Measure Issue Salience?

Mellon · 2013 · PS: Political Science & Politics · [verify] DOI not fetched

Tests Google Trends against Gallup MIP: for issues with clear, unambiguous search terms (macroeconomics, terrorism, immigration, fuel prices) search data validly tracks salience — with cautions about term ambiguity and coverage. A practical guide to when digital traces are trustworthy proxies.

Internet Search Data and Issue Salience: Properties of Google Trends

Mellon · 2014 · J. Elections, Public Opinion and Parties 24(1):45–72

The fuller companion: systematically assesses validity, reliability and comparability of Google Trends as a salience instrument, motivated by MIP being monthly and country-limited whereas search data is weekly, global and free. Core citation for deriving MIP-style signals from search traces.

Capturing Curiosity: Using Internet Search Trends to Measure Public Attentiveness

Ripberger · 2011 · Policy Studies Journal 39(2):239–259

Borrows from epidemiological search surveillance to propose Google search activity as a measure of public attention, validated against the NYT-coverage media proxy. An early, influential argument that search traces are a legitimate attentiveness instrument.

Who Leads? Who Follows? Measuring Issue Attention with Social Media Data

Barberá et al. · 2019 · APSR 113(4):883–901

Classifies the topics of legislators' and the public's tweets into daily issue-attention series, then uses vector autoregression to test who sets whose agenda. A model for measuring issue attention from social media at high temporal resolution and probing lead/lag dynamics between elites and the public. Open access at PMC.

How this connects to picking benchmark questions

For sourcing the actual political questions to test AI systems on, the highest-leverage combination is:

  • Google Trends "related queries" + WildChat / LMSYS → the literal phrasing people use, which matters for a chatbot election-information benchmark because real queries carry the framing and false premises models must handle.
  • Gallup MIP / Ipsos What Worries the World / L'ObSoCo–CEVIPOF → which topics are pressing right now, in both the US and France, on a comparable basis.
  • GDELT / Media Cloud → time-align a question to when its issue actually peaked in the news, so a benchmark item can be dated to a real salience moment.
